1. Place frontend.py, schema.sql, insert_data.sql, and queries.sql in the same folder. Then open a terminal in that folder and run: python frontend.py

2. The program will open a window titled Shop Manager. If this is your first time running it, or you want to reset the data, click "Create Project".

3. Run Required Queries opens a window with tabs showing the results of each required query for the project.

4. Display lets you pick a table (Cars, Jobs, or Customers) and view all of its records.

5. Manage Records lets you pick a table and add, update, or delete records.
To add a record, type in the information and use "Add".
To delete, select a record and use "Delete".
To update, select a record, edit the desired info, and use "Update".

6. Summary shows a report built from the Job_Summary view, listing jobs over $100 sorted by cost.
